UNO CHESS — Telegram Mini App

Содержимое этой папки — готовая статическая HTML5-сборка Godot. ИИ работает прямо в браузере; отдельный сервер для игры не нужен.

Публикация через GitHub Pages
1. Распакуйте эту папку и создайте новый репозиторий GitHub.
2. Загрузите в корень репозитория все файлы сборки: index.html, index.js, index.wasm, index.pck, index.png, index.icon.png и index.apple-touch-icon.png. Файлы должны лежать рядом, имена не менять.
3. В репозитории откройте Settings → Pages. В Build and deployment выберите Deploy from a branch, затем ветку main и папку /(root), нажмите Save.
4. Дождитесь публикации и откройте выданный адрес вида https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/ . Сначала проверьте, что игра загружается в обычном браузере.

Подключение к Telegram
1. Откройте @BotFather и создайте бота командой /newbot (или выберите уже созданного бота).
2. Отправьте /setmenubutton, выберите бота, задайте текст кнопки, например «Играть», и отправьте HTTPS-адрес GitHub Pages.
3. Откройте чат с ботом и запустите приложение кнопкой меню рядом с полем ввода.

Для главной кнопки приложения на странице профиля бота используйте @BotFather → /mybots → выберите бота → Bot Settings → Configure Mini App → Enable Mini App, затем укажите тот же HTTPS-адрес.

Важно: загружайте всю сборку, не один index.html. HTML-файл запускает соседние JS, WASM и PCK-файлы. В этой игре пока нет сетевого мультиплеера: человек играет против встроенного ИИ.
